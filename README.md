# Human O-Linked Threonine Glycosylation Site Prediction

This repository contains the final notebook and project files for predicting human O-linked threonine glycosylation (OTG) sites using deep learning and protein sequence representations.

The proposed pipeline combines protein language model embeddings with local sequence features to classify candidate threonine-centered peptide windows as OTG or non-OTG sites.
